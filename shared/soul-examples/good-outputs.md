**Не публиковать** calibration leads как готовые статьи — только слог.

## Calibration

**Слова и формулы (ход, не абзац):**

- §1 = ожог сейчас / first sentence already happened
- «Нет. Так не заселяем / не отвечаем / не переводим.»
- «Где бойлер?» / «какая собака и какая сумма?»
- quote host → break → verdict
- сначала X, потом деньги/ключ
- reader inside (you / taxi / chat / apartment)

**Длина:**

- Абзац: **1 hit**, often 1 sentence; if >3 sentences — cut.
- Лид: **8–12 коротких строк** сцены. **NO TL;DR.**
- Статья: **~900–1400 слов**, не 2500–3100.
- **Ban:** «Разберём», «В этой статье», H1 list numbers as skeleton.

**Ходы статьи:**

1. §1 сцена — ожог сейчас.
2. Диалог хоста — quote then break.
3. Lockpick question.
4. Moral + один вердикт.
5. Mid comment fight-question.
6. Чеклист **после** морали (optional).
7. «У нас так» → MAX; чеклист → TG.
8. CTA после пользы.

**Ирония:** через факт. Не стендап.

**Ритм:** рубленый, как у Клышина; голос — **тёплый хост Добрый дом**, не риэлтор.
