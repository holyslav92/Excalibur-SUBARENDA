# Post → article

Как из calibration lead собрать **guest article** Добрый дом (~**1100–1800 слов**).

## CASE delivery — 10 правил (HARD, одна формулировка)

1. §1 = плотный кейс (1–2 абзаца). **BAN** chopped 3-word lead.
2. Identity: «Я хост посуточной в Тюмени. Это «Добрый дом».» + Telegram · MAX.
3. Reader is inside (you/present tense/body in apartment/taxi/chat).
4. Number = price of burn (₽, nights, minutes). Ban H1 list numbers as skeleton.
5. Host dialogue in prose — quote then illusion break.
6. One case → one verdict. Retell with timeline numbers. Checklist AFTER moral.
7. Moral: first X, then money/key.
8. One lockpick question.
9. One mid comment fight-question (TG/MAX).
10. Guest pain only — Sol MUST NOT encyclopedia.

## Канон сборки

1. **Не копипаст** одного calibration lead на весь `article.html`.
2. Статья = **CASE**: плотный лид (цитата → удар) → identity → развитие с цифрами → moral/verdict → (optional checklist) → один CTA.
3. **Факты** — только из `drafts/writer.html` / research.
4. Лид: **1–2 плотных абзаца**. **NO chopped lead.** **NO TL;DR.**
5. H1 из `title-brief.json`. Cable + consequence. **Ban** «5 вопросов» / «7 шагов» as skeleton.
6. **~1100–1800 слов**, не checklist-landing на 9 H2.

## Каркас (CASE rhythm, голос Добрый дом)

| Часть | Что делать | Чего не делать |
| --- | --- | --- |
| §1 | Плотный кейс на первом экране | Chopped lead, TL;DR, «в этой статье» |
| Identity | One-liner + TG · MAX | Баннер-дамп в §1 |
| Таймлайн | Даты, ночи, ₽, детали | Монолог-энциклопедия |
| Диалог | Quote → illusion break | Список терминов |
| Lockpick | «Где бойлер?» / «сколько минут до вуза?» | — |
| Moral | First X, then money/key | Сначала перевод |
| Verdict | Одна фраза на кейс | 8 H2 checklist spine |
| Чеклист | **После** moral | Вместо сцены |
| CTA | **Один** блок в конце | Double MAXили |

## Длина

- Лид: 1–2 плотных абзаца (не 8–12 рубленых строк).
- Статья: ~1100–1800 слов.
- **Dzen pattern 1** (N советов) — **NOT default**.

## Writer vs Sol

- Writer — смысл и факты (сцена, verdict, moral, обязательные 5 элементов).
- Sol — ритм из `SOUL.md` и `good-outputs.md`.
- **Sol MUST NOT** replace burn scene with how-to.
- После Sol прозу не переписывают, кроме возврата Sol при FAIL.
