# Post → article

Как из короткого слога собрать **guest article** Добрый дом (~**900–1400 слов**).

## Klyshin delivery — 10 правил (HARD, одна формулировка)

1. §1 = ожог сейчас. First sentence already happened. Ban TL;DR / «в этой статье» / «разберём N».
2. Paragraph = 1 hit. Often 1 sentence. If >3 sentences, cut.
3. Reader is inside (you/present tense/body in apartment/taxi/chat).
4. Number = price of burn or fix (00:12, 1500₽, 4 kg). Ban H1 list numbers («5 вопросов», «7 шагов») as article skeleton.
5. Host/aggregator dialogue is evidence. Quote then break it.
6. One case → one verdict. Checklist AFTER moral, never instead of scene.
7. Moral: first X, then money/key. Not the reverse.
8. One lockpick question (like «где спит бабушка?» mapped to guest: «Где бойлер?» / ««Можно» — какая собака и какая сумма?»).
9. Refusal beat after excuse: «Нет. Так не заселяем / не отвечаем / не переводим.»
10. Scout/Title = guest pain only. Delete ЕГРН/наследство/ипотека/Шакин. Sol MUST NOT replace burn scene with how-to.

## Канон сборки

1. **Не копипаст** одного calibration lead на весь `article.html`.
2. Статья = цепочка **битов**: сцена → диалог → lockpick → moral/verdict → (optional checklist) → CTA.
3. **Факты** — только из `drafts/writer.html` / research.
4. Лид: **8–12 коротких строк** сцены. **NO TL;DR.**
5. H1 из `title-brief.json`. Cable pain-scene. **Ban** «5 вопросов» / «7 шагов» as skeleton.
6. **~900–1400 слов**, не longform 2500–3100.

## Каркас (ритм Клышина, голос Добрый дом)

| Часть | Что делать | Чего не делать |
| --- | --- | --- |
| §1 | Ожог сейчас; reader inside | TL;DR, «в этой статье», «разберём N» |
| Диалог | Quote host → break | Монолог без голоса хоста |
| Lockpick | «Где бойлер?» / «какая собака?» | Список терминов |
| Moral | First X, then money/key | Сначала перевод, потом условия |
| Refusal | «Нет. Так не…» после отговорки | Мягкая лекция |
| Verdict | Одна фраза на кейс | Энциклопедия H2 |
| Чеклист | **После** moral | Вместо сцены |
| CTA | TG/MAX/booking после пользы | Link dump в конце |

## Длина бита

- Абзац: **1 hit**, often 1 sentence; if >3 — cut.
- Лид: 8–12 строк сцены.
- Статья: ~900–1400 слов.
- **Dzen pattern 1** (N советов) — **NOT default**.

## Writer vs Sol

- Writer — смысл и факты (сцена, verdict, moral).
- Sol — ритм из `SOUL.md` и `good-outputs.md`.
- **Sol MUST NOT** replace burn scene with how-to.
- После Sol прозу не переписывают, кроме возврата Sol при FAIL.
