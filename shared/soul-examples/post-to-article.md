# Post → article

Как из короткого слога собрать **longform** блога The Риэлтор (~2000–2600 слов).

## Канон сборки

1. **Не копипаст** одного поста на весь `article.html`.
2. Статья = цепочка **битов** под H2. Каждый бит: тезис → диалог/контраст → шаг проверки → удар (вердикт).
3. **Факты** — только из `drafts/writer.html` / research.
4. Лид: крючок-вопрос или сцена «кажется чисто» → «покажу изнутри».
5. H1 из `title-brief.json`. Без SEO-хвоста.
6. **Минимум 7 H2** до FAQ — под Cover `inline_1…inline_7`.

## Каркас (ритм Клышина, голос Шакина)

| Часть | Что делать | Чего не делать |
| --- | --- | --- |
| Лид | Крючок-вопрос или сцена риска | Глоссарий, «в этой статье» |
| Напряжение | «Кажется чисто» → что не видно | Паника, кликбейт |
| Изнутри | «Расскажу, как проверяют до аванса» | «Гарантирую нулевой риск» |
| Диалог | Реплика читателя в кавычках | Монолог без голоса читателя |
| Контраст | Обычный видит X / риэлтор спрашивает Y | Сухой список терминов |
| TL;DR | 3–6 коротких строк | Копипаст лида |
| H2-биты | Чеклист, таблица, «где теряют деньги» | Вода «виды недвижимости» |
| Вердикт | Одна фраза на секцию | Слоган агентства |
| Финал | Предел компетенции + дисклеймер | «Покупайте сейчас» |
| CTA | Один раз после пользы | В каждом абзаце |

## Длина бита

- 1 мысль = 1 H2.
- Абзац: 1–3 предложения, часто одно.
- Чеклист: глаголы (запросите, проверьте, зафиксируйте).
- География Тюмени — когда меняет проверку.

## Writer vs Sol

- Writer — смысл и факты.
- Sol — ритм из `SOUL.md` и `good-outputs.md`.
- После Sol прозу не переписывают, кроме возврата Sol при FAIL.
