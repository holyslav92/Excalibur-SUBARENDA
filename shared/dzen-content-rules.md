# Dzen + РФ — канон до любого Scout

**HARD:** Директор и Scout **читают этот файл целиком** и
`shared/rf-blocked-entities.json` **до** выбора темы / `research_start`.
Без этого шага пайплайн не стартует.

Официальные источники Дзена (актуализировать по ссылкам, не по памяти):

1. https://dzen.ru/help/ru/requirements/rules.html — **требования к контенту** (все публикации)
2. https://dzen.ru/help/ru/requirements/content.html — Новости в Дзене: содержание
3. https://dzen.ru/help/ru/requirements/content_requirements.html — качество / заголовки
4. https://dzen.ru/help/ru/requirements/access.html — доступ к информации (RSS/партнёры)
5. https://dzen.ru/legal/ru/ — условия использования сервиса

Блог и Дзен читают **одну** статью → Title / Writer / Cover обязаны
соблюдать эти правила. Gate: `topic_focus` + doctor preflight.

## 0. Закон РФ (перекрывает хайп)

Дзен прямо требует **соблюдение законодательства РФ** и запрещает
материалы, которые толкают обходить закон (в т.ч. VPN для запрещённых
сайтов) — см. «Незаконная информация» в `rules.html`.

### Meta / Facebook / Instagram — BLOCK как герой темы

- Тверской районный суд г. Москвы, 21.03.2022: деятельность
  **Meta Platforms Inc.** по реализации **Facebook** и **Instagram**
  запрещена в РФ по основаниям экстремистской деятельности
  (апелляция Мосгорсуда 20.06.2022 оставила в силе).
- **Новые** темы, где Meta / Facebook / Instagram / Meta AI / Muse Code /
  Muse Spark / Threads — субъект новости, how-to, автопостинг, обзор
  продукта → **TOPIC FOCUS BLOCKER**. Не публиковать в блог/Дзен.
- Не путать с техническим термином **meta-теги** (SEO) — это разрешено.
- WhatsApp в решении суда выделен отдельно (нет функции публичного
  распространения); **всё равно** не делаем Meta-продукт героем статьи
  без крайней необходимости. При сомнении — **не брать**.
- Логотипы / символика запрещённых продуктов Meta — не ставить на обложку
  и не продвигать как канал роста.

### Другие площадки с блокировкой / запретом в РФ (новые темы)

Не делаем **героем how-to / news review** (автопостинг «как залить сюда»,
«как вести канал»):

| Сущность | Статус для нас |
|----------|----------------|
| Instagram, Facebook, Meta, Threads, Muse* | **DENY** |
| LinkedIn | **DENY** (блокировка РКН) |
| X / Twitter | **DENY** (блокировка) |
| Discord | **DENY** (блокировка) |
| Signal, Viber (как герой how-to) | **DENY** при сомнении |
| VPN / обход блокировок | **DENY** (прямо в rules.html Дзена) |

Разрешённые каналы доставки для CTA/автопостинга в ядре блога:
**Telegram, VK, Дзен, MAX** и CTA-ссылки тенанта из `shared/tenant-config.json`.
Список сущностей для скрипта: `shared/rf-blocked-entities.json`.

Исторические статьи в ledger (старый Instagram-автопостинг и т.п.) —
факт прошлого; **новые** карточки по DENY — BLOCK.

## 1. Дзен `rules.html` — сводка запретов

Источник: https://dzen.ru/help/ru/requirements/rules.html

- **Азартные игры / лотереи** — без призывов, ссылок, стратегий «как
  выиграть»; исторический/художественный контекст — ок.
- **Ненависть и насилие** — по любому признаку (раса, нация, вера,
  возраст, политика, миграция и т.д.); без оскорблений и теорий заговора
  про конкретных людей.
- **Искусственное завышение** метрик — запрещено.
- **Кликбейт** карточки — обман ожиданий → показ только подписчикам /
  риск канала.
- **Медицина** — доказательная; без схем самолечения; к врачу.
- **Незаконная информация** — наркотики, оружие, взрывчатка, торговля
  людьми; призывы к преступлениям; дистанционная продажа алкоголя/
  никотина; ответы ЕГЭ/ОГЭ; пропаганда ЛГБТ / педофилии / смены пола /
  чайлдфри (по формулировкам закона РФ в справке Дзена); **VPN и обход
  запрещённых сайтов**; суицид / диггерство / руфинг и т.п.; любой
  контент + ссылки, нарушающие закон.
- **Неоригинальный контент** / чужие права — ограничивать.
- **Откровенный / шок-контент** — ограничения; шок → только подписчикам.
- **Происшествия/трагедии** — спекуляция → без монетизации.
- **Спам** — off-topic навязчивое.
- Те же правила на **карточки** и **комментарии**.

## 2. Новости в Дзене (`content.html` + `content_requirements.html`)

- Соблюдение РФ закона; без призывов к насилию/ненависти/оскорблений.
- **Мат запрещён полностью**, в т.ч. с заменой символами.
- Новостной/аналитический характер; **не**: афиши, погода, гороскопы,
  рецепты, чистые списки/таблицы, авторские колонки, обзоры комментов
  в соцсетях, стихи/фельетон, «главное за день», внутренние акции
  редакции, энциклопедия/биография ради справки.
- Без рекламы/антирекламы продукта/личности/организации.
- Заголовки/тексты не вводят в заблуждение, без кликбейта и оценочных
  суждений, без устаревшей информации.
- Без шок/откровенного контента.
- Без орфо-/речевых/синтаксических/семантических ошибок; тексты не должны
  быть «написаны алгоритмами ML» в смысле справки — у нас голос
  автора корпуса / живой русский, не SEO-робот.
- Заголовок: прямой порядок слов, конкретный источник если нужен,
  без метафор/штампов/жаргона/инверсии/«открывашек»/оценки как факта.

## 3. Что это значит для пайплайна

| Роль | Обязанность |
|------|-------------|
| **Директор** | Preflight: doctor + today + **прочитать этот файл** + rf-blocked; только потом Scout |
| **Scout** | Не выбирать DENY-сущности; focus gate; Дзен+РФ до handoff |
| **Title** | Дзен-заголовки; без Meta/IG/… в H1 |
| **Writer** | Текст по Дзену; без продвижения запрещённых площадок |
| **Cover** | Без логотипов/символики запрещённых сущностей |
| **Publish** | Не выкладывать, если focus/RF gate FAIL |

## 4. Gate

```bash
python3 scripts/excalibur_blog_doctor.py   # проверяет наличие канона
python3 scripts/excalibur_blog_topic_focus.py --text "<title>"
# DENY из rf-blocked-entities.json подхватывает topic_focus
```

Structural / publish BLOCK при: мате; кликбейт/оценка в H1; обзор
комментов вместо материала; VPN/обход; герой = RF-blocked entity.


## Нормативность

Без ненормативной лексики (мата) в материалах под Дзен.
