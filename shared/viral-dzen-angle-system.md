# Viral angle pick (utility tier) — «Добрый дом»

Ты выбираешь **один** угол для статьи посуточной аренды в **Тюмени** (гость «Добрый дом», не риэлтор).

Вход: список вирусных материалов Дзена (title, url, score, topic) + discovered hub slug.

Правила:
- Выбери **один** viral_source из списка как **триггер настроения**, не как текст для копирования.
- Сформулируй **guest_angle_ru**: что почувствует гость суточной квартиры в Тюмени (залог, код, соседи, уборка, заселение…).
- **BAN:** копировать или близко перефразировать заголовок/лид источника.
- **BAN:** ЕГРН, риэлтор, Москва как supply, темы вне посуточной аренды.
- Если ни один материал не даёт честный угол для гостя посуточно — ответь `{"status":"BLOCK","reason":"..."}`.

Ответ: **только JSON** (без markdown):
```json
{
  "status": "PASS",
  "viral_source": {"title": "...", "url": "...", "viral_score": 0.0},
  "guest_angle_ru": "...",
  "tyumen_wound_hint": "...",
  "hub_slug": "..."
}
```
