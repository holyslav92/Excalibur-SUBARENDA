# Dzen card description — канон (Description agent)

**Роль:** `excalibur-blog-description` — **после Sol**, **до Cover-text**.  
**Выход:** `description-brief.json` в папке статьи.

Карточка Дзена = **вторая строка** к заголовку. Не дублирует H1 и не обрезает лид статьи.  
Тот же текст → WP `post_excerpt` → RSS/og:description.

---

## Что это

- **1–2 предложения**, ~120–220 символов (макс. 250).
- **Ритм Klyshin:** case hook, разговорная первая реплика, интрига до клика.
- **Автор / бренд:** **Добрый дом** (посуточная аренда Тюмень). **Не** Святослав Шакин, **не** The Риэлтор.
- **Guest pain only** — залог, код, соседи, животные, бойлер… **Не** ЕГРН/наследство/ипотека.

---

## OG / description factory (HARD)

1. **NEVER** put guest-burn arithmetic (e.g. 2500→6500) in og:description **as if it is Добрый дом's own price**.  
   Live bug: «у Доброго дома две ночи по 2500… 6500» — бренд выглядит мошенником.  
   Teaser = **ожог/риск**, не прайс-лист бренда. Одна сумма как hook — OK; **лестница цен** или «у Доброго дома … ₽» — FAIL.

2. **NEVER** mention **Святослав Шакин** / **The Риэлтор** in og:description.  
   Live bug: «история Святослава Шакина». Author = **Добрый дом**.

3. **≠ title** — не совпадает с `title-brief.json` → `h1` / `title`.
4. **≠ truncated lead** — не подстрока первых двух абзацев `article.html`.
5. **Не label head** — не «Проверка заселения», не «Риэлтор Тюмень».
6. **Не спойлер всей статьи** — один крючок, не чеклист из 5 пунктов.
7. **Кириллица** — латиница только для брендов (MAX, Wi‑Fi).
8. **Дзен + РФ** — `shared/dzen-content-rules.md`.

---

## Примеры энергии (не копировать)

| Title (H1) | Description (teaser) — OK |
|------------|---------------------------|
| Код есть — из крана льёт холодное | Хост пишет «утром будет». Вы уже в квартире. Где бойлер — спросите до того, как замёрзнете. |
| В чате «можно с собакой» — у двери «не пустим» | «Можно» без породы и доплаты — не ответ. Один вопрос в переписке спасает заселение. |

| Description — FAIL |
|--------------------|
| У Доброго дома две ночи по 2500 вышли 6500 с доплатами |
| История Святослава Шакина: как не переплатить за сутки |

## Gate

```bash
python3 scripts/excalibur_blog_description_gate.py --article-dir <dir>
```

`verdict: PASS` только если все проверки выше OK.
