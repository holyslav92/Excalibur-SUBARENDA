# Dzen card description — канон (Description agent)

**Роль:** `excalibur-blog-description` — **после Sol**, **до Cover-text**.  
**Выход:** `description-brief.json` в папке статьи.

Карточка Дзена = **вторая строка** к заголовку. Не дублирует H1 и не обрезает лид статьи.

---

## Что это

- **1–2 предложения**, ~120–220 символов (макс. 250).
- **Ритм Klyshin:** case hook, разговорная первая реплика, интрига до клика.
- **Факты и город:** Святослав Шакин / Тюмень (не копипаст @klyshin_A).
- **Demand spine:** можно намекнуть на buyer-риск (ЕГРН, аванс, наследство), без SEO-хвоста.

## Обязательные правила

1. **≠ title** — не совпадает с `title-brief.json` → `h1` / `title` (посимвольно, casefold).
2. **≠ truncated lead** — не является подстрокой первых двух абзацев `article.html` (после strip tags); не начинается с той же фразы, что первый `<p>`.
3. **Не label head** — не «Проверка ЕГРН», не «Риэлтор Тюмень».
4. **Не спойлер всей статьи** — один крючок, не чеклист из 5 пунктов.
5. **Кириллица** — латиница только для брендов (ЕГРН, ЦИАН, Домклик).
6. **Дзен + РФ** — те же DENY, что в `shared/dzen-content-rules.md` (Meta/Instagram…).

## Примеры энергии (не копировать)

| Title (H1) | Description (teaser) |
|------------|---------------------|
| В выписке ЕГРН есть строка, после которой аванс вносить нельзя | Продавец говорит «всё чисто». Одна строка в реквизите 4 говорит обратное — и аванс уже поздно отменять без нервов. |
| Расписку написали. Денег не получили | Договор подписан, расписка на столе. А деньги так и не пришли — потому что расчёт начали не с того конца. |

## Gate

```bash
python3 scripts/excalibur_blog_description_gate.py --article-dir <dir>
```

`verdict: PASS` только если все проверки выше OK.
