# Research — официальные источники (тарифы и условия компаний)

## Зачем

Ошибка B02: тариф Сбера для **юрлиц** (0,3% / мин. 15 000 ₽) попал в статью про
сделку **физлиц**. Обзоры и legal-страницы банка легко перепутать с тарифом для
граждан. Такие юридические промахи дороже, чем комментарии в Дзене.

## Жёсткое правило

Если в `practical_facts` / `constraints` есть **цифра, процент, комиссия, тариф,
срок, лимит** от имени компании (банк, застройщик, Росреестр, нотариат):

1. Research **обязан** открыть **официальный сайт** этой компании.
2. Зафиксировать **аудиторию**: физлица / юрлица / ИП / ипотека — отдельно.
3. Записать в `## official_verifications` (см. шаблон).
4. В `source_table` — строка `type: official` с **тем же URL**, что в верификации.
5. Обзоры (МИР КВАРТИР, ГрадБейс, медиа) — только как **вилка/контекст**, не как
   единственный источник цифры.

**Запрещено:** брать тариф банка только с `/ru/legal/` для статьи про бытовую
покупку квартиры физлицом без явной пометки «это юрлица».

## Шаблон в research-notes.md

```markdown
## official_verifications

| claim | audience | value | official_url | accessed_at | verified |
|-------|----------|-------|--------------|-------------|----------|
| Сбер: комиссия за аккредитив при купле-продаже недвижимости | физлица | 3 400 ₽ | https://www.sberbank.ru/ru/person/payments/special_acc/accreditive | 2026-08-20 | yes |
| Сбер: аккредитив (корп.) | юрлица | 0,3% / мин. 15 000 ₽ | https://www.sberbank.ru/ru/legal/bankingservice/loc | 2026-08-20 | yes (не для физлиц в бытовой сделке) |
```

## research-agent-report.json

Добавить блок:

```json
"official_source_audit": {
  "required": true,
  "status": "PASS",
  "verified_claims": 2,
  "entities_checked": ["sberbank"],
  "errors": []
}
```

`status: BLOCK` — если есть тарифный claim без official_verifications или URL не
с официального домена.

## Алгоритм Research (обязательный)

1. Выписать все **числовые claims** про компании из черновика фактов.
2. Для каждого банка/бренда — **WebFetch / браузер** на официальный домен.
3. Сверить: физ / юр / ипотека — **разные страницы**.
4. Если официальный сайт недоступен из Cloud — `official_source_audit.status =
   BLOCK`, fact не передаётся Writer как «точная цифра»; только формулировка
   «уточнять в отделении письменно».
5. В `constraints` явно: «цифры банков — сверять по person-разделу для физлиц».

## Writer / Sol

- Цифры банков и госорганов — **только** из `official_verifications` +
  `practical_facts`, помеченных как official.
- Вилка из обзоров — с оговоркой «по рынку / в обзорах», не как единственный факт.
