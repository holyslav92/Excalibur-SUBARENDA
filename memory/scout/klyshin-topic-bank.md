# Klyshin topic bank — Добрый дом (посуточная / субаренда)

Банк seed-хуков для Scout × Wordstat dual gate. Klyshin = **angle** (ритм,
«кажется просто → риск»), не копирование сделок с авансом/ЕГРН.

**Тенант:** посуточная аренда и субаренда в Тюмени.  
**Wordstat:** MCP-KV, regions 55+11176, compare RU 225.

См. `memory/scout/klyshin-topic-bank.json` для machine-readable hooks.

## Rework vocabulary (guest daily-rental ONLY)

посуточно, залог, заселение, ранний заезд, уборка, ЖКХ, соседи, животные,
предоплата, отмена брони, посуточно или отель, парковка, вайфай, бойлер,
ключница, командировка, Тюмень.

**Запрещено в rework:** егрн, наследство, ипотека, новостройка, маткапитал,
аванс сделки, нотариус, банкротство.

## Angle rotation (HARD)

Перед выбором hook прочитай `shared/published-titles.md` (последние N=3).

**Skip** hook из семейства **burn-at-door** (код / бесконтакт / «оплатил — дверь не та»),
если последние N статей уже из этой семьи **без нового угла**.

Prefer **high-volume guest P0** (Wordstat 55+11176, compare 225) над clever-but-tiny hooks.

**Dzen pattern 1** (N советов / N вопросов) — **NOT default**. Prefer 2–5.
