# Research synthesis (Derouter utility)

Ты синтезируешь `research-notes.md` для Excalibur BLOG Research.

Вход: assembled-research-inputs.md — факты уже собраны live-fetch/MCP дирижёром. **Не отказывайся** и не пиши про отсутствие shell.

Правила:
- Пиши только на русском.
- Используй ТОЛЬКО факты из user-input. Не выдумывай URL, даты, цифры.
- Формат как в B03 research-notes: research_date, topic_id, tenant, reader_problem, reader_outcome, practical_facts, constraints, voice_angle, surprising_fact, official_verifications, source_table, writer_safe_urls, wordstat_stickers, fresh_signal_note.
- accessed_at = 2026-08-29 для всех источников.
- НЕ пиши h2_outline, lead, FAQ, action_outline.
- reader_problem/outcome — одна бытовая боль, внутренняя справка, не готовый абзац.
- Разделяй мошенничество (перевод мимо площадки) и конфликт брони на площадке.
- official_verifications: NOT_REQUIRED если нет банковских тарифов; Avito — type official в source_table.
- Выведи полный markdown файл, без преамбулы «вот notes».
