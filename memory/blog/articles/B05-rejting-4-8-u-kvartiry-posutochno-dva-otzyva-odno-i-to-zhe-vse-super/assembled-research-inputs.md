## Official platform sources

### Avito — блог для посуточников (cached fetch 2026-09-01)
URL: https://www.avito.ru/blog/kak-posutochniku-rastit-reyting-na-avito

Key facts:
- Рейтинг = среднее арифметическое оценок 1–5 звёзд; для частников после первой оценки, для компаний — после третьей.
- На рейтинг влияют только отзывы типов «Проживание состоялось» и «Не удалось заселиться».
- Отзывы «Не договорились» и «Не общались» не входят в рейтинг, но показываются в «Отзывы без оценки».
- Хозяева **могут и должны просить** гостей оставить отзыв (личные сообщения, кнопка «Запросить отзыв» в профиле).
- С 15.06.2023 онлайн-бронирование обязательно для посуточных на Авито; платформа **автоматически запрашивает отзывы** у гостей.
- Причины отклонения отзыва модерацией: подозрение на накрутку; персональные данные; нарушение закона; нет доказательств проживания.
- Avito рекомендует хозяевам не использовать **шаблонные одинаковые ответы** на отзывы — «как робот».

### Sutochno.ru — система отзывов (web search snippets; blog 500 error 2026-09-01)
URLs:
- https://sutochno.ru/blog/otzyvy
- https://sutochno.ru/sj/kak-pravilno-snyat-kvartiru
- https://sutochno.ru/sj/kak-zabronirovat-zhile-i-ne-bespokoitsya

Key facts from snippets:
- Гость и хозяин оценивают друг друга; **14 дней** после выезда на отзыв.
- Взаимная система: отзывы скрыты, пока обе стороны не оценят или не истечёт срок.
- Средний балл в поиске показывается при **минимум двух отзывах** (по 6 критериям в гостевой оценке).
- Отзывы оставляют только пользователи, бронировавшие через сервис; «произвольный отзыв» нельзя.
- Платформа заявляет модерацию каждого отзыва.
- Гостям советуют читать отзывы перед бронированием; есть фильтр по оценке (например 9+).
