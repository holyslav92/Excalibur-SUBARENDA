- **Правовед 5023780** (16.08.2025): закон не обязывает разрешать фотографировать/сканировать паспорт; можно показать оригинал для переписывания или заполнить анкету самому. Отказ гостиницы при предъявлении оригинала — незаконное ущемление прав потребителя (аналогия для гостя).
- **Правовед 5006541** (18.07.2026): при бесконтактном заселении передача паспортных данных для договора допустима, но **только через чат площадки (Суточно.ру) или защищённый сервис**, не в личные мессенджеры. Договор можно подписать удалённо (63-ФЗ: СМС, ЭП, акцепт офертой). Альтернатива: договор ждёт в квартире, данные вписать при заселении.
- **Контур.Отель FAQ**: копии паспортов иностранцев — обязанность по 109-ФЗ; для граждан РФ — **только с согласия** по 152-ФЗ.
